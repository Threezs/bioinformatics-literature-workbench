# Literature folders

- `inbox/`: temporary DOI/BibTeX imports; do not commit PDFs.
- `notes/`: one structured QMD/Markdown note per paper.
- `reviews/`: synthesis pages grouped by pathway, model or research question.
- `protocols/`: reusable experimental and bioinformatics methods.

Use filenames such as `P001_author_year_topic.qmd` and keep the stable `paper_id` in front matter.
